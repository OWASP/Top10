# OWASP Top 10:2025

欢迎阅读 OWASP Top 10:2025 版本。

OWASP Top 10 是一份面向开发者和 Web 应用程序安全的标准意识文档，它代表了关于 Web 应用程序最严重安全风险的广泛共识。

## 关于本版本

这是 OWASP Top 10 的 **2025** 版本。本版本基于最新数据和安全趋势进行了更新。

[主项目页面](https://github.com/OWASP/www-project-top-ten) 包含有关旧版本的信息以及本项目的元数据。
