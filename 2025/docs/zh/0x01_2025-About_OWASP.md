# 关于 OWASP

开放全球应用安全项目（OWASP）是一个开放的社区，致力于帮助组织开发、采购和维护可信赖的应用程序和 API。

在 OWASP，您可以免费获取以下开源资源：

- 应用安全工具与标准
- 前沿研究
- 标准安全控制与库
- 关于应用安全测试、安全代码开发和安全代码审查的完整书籍
- 演示文稿与 [视频](https://www.youtube.com/user/OWASPGLOBAL)
- 涵盖众多常见主题的 [速查表](https://cheatsheetseries.owasp.org/)
- 在全球及线上举办的 [Chapters meetings](https://owasp.org/chapters/)
- [活动, 培训和会议](https://owasp.org/events/)
- [Google Groups](https://groups.google.com/g/owasp)

了解更多信息，请访问：[https://owasp.org](https://owasp.org)。

所有 OWASP 的工具、文档、视频、演示文稿和分会均免费开放，欢迎任何对提升应用安全感兴趣的人士使用。

我们主张将应用安全视为一个涉及人员、流程和技术的综合性问题，因为最有效的应用安全方法需要在这些方面同时改进。

OWASP 是一个与众不同的组织。我们不受商业压力影响，能够提供关于应用安全的客观、实用且经济高效的信息。

OWASP 不与任何技术公司存在关联，但我们支持在知情前提下合理使用商业安全技术。OWASP 以协作、透明和开放的方式制作多种类型的材料。

OWASP 基金会是一个非营利实体，负责确保项目的长期成功。几乎所有与 OWASP 相关的人员都是志愿者，包括 OWASP 董事会、分会负责人、项目负责人和项目成员。我们通过资助和基础设施支持创新安全研究。
